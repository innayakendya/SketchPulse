# SketchPulse

SketchPulse is a cloud-based, distributed engine that streamlines real-time data processing through auto-scaling and load-balanced architecture.

The key benefits of using SketchPulse include:

- SketchPulse is a cloud-based, distributed
- engine that streamlines real-time data
- processing through auto-scaling and load-balanced

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchPulse.git`
2. `cd SketchPulse`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
